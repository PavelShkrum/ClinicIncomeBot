# История изменений

## v1.0.0 — первый стабильный MVP

### Возможности

- добавление нескольких поликлиник;
- отдельные цены первичного и вторичного приёма;
- быстрое добавление приёма через кнопки;
- статистика за сегодня;
- статистика за текущий месяц;
- статистика за выбранный период через календарь;
- удаление последнего ошибочного приёма;
- изменение цен без пересчёта старых записей;
- доступ только для разрешённых Telegram-аккаунтов;
- административные права для двух владельцев;
- хранение данных в SQLite;
- автоматические ежедневные резервные копии;
- запуск на Ubuntu 24.04 через systemd;
- автоматическая проверка Python-кода через GitHub Actions.

### Безопасность данных

Бот не хранит имена пациентов, телефоны, диагнозы и другие медицинские или персональные данные.
